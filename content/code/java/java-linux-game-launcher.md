J'aime les jeux vidéo. J'aime Linux. Donc j'ai créé un projet pour installer les jeux vidéo Windows sur Linux. 
Mais pourquoi ? Il y a déjà plein de projets qui le permettent.

Je suis quelqu'un qui aime posséder mes jeux, j'essaie d'acheter principalement sur [GoG](https://www.gog.com/) car le jeu n'a pas de DRM, et on peut télécharger notre backup de jeu et le conserver nous-même sans dépendre d'un service internet. 
Mais voilà des launchers qui permettent de gérer cela, ça existe, comme [Heroic Game Launcher](https://heroicgameslauncher.com/) mais bon besoin est assez différent. 

Je souhaite que :  
- Ma liste de jeux ne soit pas liée à mon compte GoG. J'ai de très vieux jeux qui proviennent d'ailleurs.  
- Ma liste de jeux sera construite à partir de mon NAS.  
- Supporter différentes versions de Proton.  
- Supporter différentes méthodes d'installation.  
- Avoir plusieurs options simples et rapides à ajouter.


Ce launcher écrit en JAVA et utilise [Umu](https://github.com/Open-Wine-Components/umu-launcher) et [Proton GE](https://github.com/GloriousEggroll/proton-ge-custom).  
Il supporte [Gamescope](https://github.com/ValveSoftware/gamescope), [Feral GameMode](https://github.com/FeralInteractive/gamemode) et [MangoHud](https://github.com/flightlessmango/MangoHud).
